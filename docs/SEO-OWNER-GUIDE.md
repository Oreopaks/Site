# SEO: что делает владелец

Сайт: `https://regiondorstroy.com/` (главное зеркало — https, без www). Всё, что вводится на сайт,
вводится в админке: `/admin/` → «Настройки» → вкладка.

| Вкладка | Что там | Кто правит |
|---|---|---|
| «Посадочные» | title, description, H1 и подводка четырёх страниц услуг; сверху — какие страницы опубликованы и каких полей не хватает | владелец, менеджер, редактор |
| «Анкета» | ответы на вопросы `fact_*` (см. `docs/owner-questionnaire.md`) — из них собираются FAQ и разделы страниц | владелец, менеджер |
| «Метрика и вебмастера» | ID Метрики, коды подтверждения Яндекс Вебмастера и Google Search Console | только владелец |
| «SEO» | `base_url` — адрес сайта, на нём строятся canonical и sitemap | владелец, менеджер, редактор |

Страницы услуг: `/arenda-spetstekhniki/`, `/shcheben-pesok-grunt/` — опубликованы;
`/asfaltirovanie/`, `/blagoustroystvo/` — отдают 404, пока в «Анкете» не заполнен ответ о видах работ.
Сайт сам выкладывает только то, что вы написали: без ответа блок или страница не показываются.

## Яндекс Вебмастер

1. https://webmaster.yandex.ru → добавить сайт `https://regiondorstroy.com/`.
2. Способ подтверждения — «Метатег». Из тега `<meta name="yandex-verification" content="…">` скопировать
   **только значение `content`** → админка, «Метрика и вебмастера» → «Код подтверждения Яндекс Вебмастера»
   → Сохранить → в Вебмастере «Проверить». Тег ставится в `<head>` главной — там Яндекс его и ищет
   (в другом месте права не подтвердятся).
3. «Индексирование» → «Файлы Sitemap» → `https://regiondorstroy.com/sitemap.xml`
   (в нём главная и опубликованные страницы услуг; ссылка есть и в `robots.txt`).
4. «Индексирование» → «Переезд сайта» / главное зеркало: `https://regiondorstroy.com` (без www).
5. Регион: Яндекс присваивает его по **фактическому адресу компании, указанному на сайте**, и, как правило,
   только один. Пока адреса на сайте нет (реквизиты пусты) — регион не присвоить; нужен ответ на вопрос 15 анкеты.

## Яндекс Бизнес

- Карточка организации: тот же телефон, часы работы и сайт, что на сайте (сейчас на сайте — «Пн–Сб, 8:00–20:00»).
- Адрес офиса или базы; если его не показываете — зона выезда.
- Услуги и реальные фото техники и объектов.
- **Виджет отзывов на сайт не ставить.** Это сторонний скрипт: сайт работает без чужих скриптов,
  а в политике конфиденциальности сторонние сервисы не описаны. Вместо виджета можно дать обычную
  ссылку на карточку (например, пунктом меню в «Контенте»).

## Яндекс Метрика

Сейчас выключена (поле ID пустое — на сайте нет ни счётчика, ни cookie-баннера).
Включать только после отдельной юридической проверки и правки политики конфиденциальности
(`LEGAL-HOSTING-RESEARCH.md`: позиция РКН по cookie и Метрике не получена). После этого —
ID счётчика в «Метрика и вебмастера»: баннер «Принять / Отклонить» и раздел в политике
появятся сами, счётчик грузится только после «Принять».

## Google Search Console

1. https://search.google.com/search-console → «Добавить ресурс» → **«Ресурс с префиксом в URL»**
   → `https://regiondorstroy.com/`.
2. Подтверждение «HTML-тег»: значение `content` из `<meta name="google-site-verification" …>` →
   «Метрика и вебмастера» → «Код подтверждения Google Search Console» → Сохранить → «Подтвердить».
3. «Файлы Sitemap» → `sitemap.xml`.

Коды подтверждения вводит только владелец: кто подтвердил права, тот управляет сайтом в поиске.

## Отзывы

- Просите реальных клиентов оставлять отзывы на Яндекс Картах и в 2ГИС.
- Не покупать отзывы и не писать их самим.
- На сайт разметку отзывов и рейтинга (Review, AggregateRating) **не ставить**: Google не показывает звёзды
  отзывов, которые компания собирает о себе сама, и запрещает собирать рейтинг с других сайтов.
- Проверить карточку на Zoon с оценкой 1,5 — ваша ли это фирма (вопрос 19 анкеты).

## Чек-лист после деплоя

До выкладки (делает разработчик, README → «Шаги M7»): черновик в админке опубликован или отменён;
сертификат покрывает `www.regiondorstroy.com`; в «SEO» `base_url` = `https://regiondorstroy.com/`.

После выкладки:

```sh
curl -sI https://www.regiondorstroy.com/                      # 301 → https://regiondorstroy.com/
curl -sI https://regiondorstroy.com/arenda-spetstekhniki      # 301 → …/arenda-spetstekhniki/
curl -sI https://regiondorstroy.com/arenda-spetstekhniki/     # 200
curl -sI https://regiondorstroy.com/shcheben-pesok-grunt/     # 200
curl -sI https://regiondorstroy.com/asfaltirovanie/           # 404 (до ответа в анкете)
curl -sI https://regiondorstroy.com/admin                     # 301 → /admin/
curl -s  https://regiondorstroy.com/sitemap.xml | grep -c '<loc>'   # 3
```

Затем Вебмастер → «Инструменты» → «Проверка ответа сервера» для `/arenda-spetstekhniki/`
и `/shcheben-pesok-grunt/` — код 200. В коде страницы `<link rel="canonical">` должен начинаться
с `https://regiondorstroy.com/` (если там другой адрес — не исправлен `base_url`).

Когда ответите в анкете о видах асфальтовых работ или благоустройства — соответствующая страница
откроется сама и появится в sitemap; в Вебмастере её можно отправить на переобход.
