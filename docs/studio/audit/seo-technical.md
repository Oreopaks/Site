# Техническое SEO — аудит 2026-11-08

Источник: прод regiondorstroy.com (только GET, curl), `var/studio/m0/measure.*`, `docs/studio/seo/webmaster.md`, код `public/`. Выдачу Яндекса не проверить — позиции не утверждаю.

## Что в порядке (проверено curl -sI)
- http→https, www→apex: одним 301 на `https://regiondorstroy.com/` (4 варианта).
- Слеш: `/arenda-spetstekhniki` → 301 `/arenda-spetstekhniki/`. `/index.php` отдаёт 200, но canonical = `/`.
- 404: настоящий код 404 (`/nope`, `/asfaltirovanie/`, `/blagoustroystvo/`), страница с `noindex`, 4,3 КБ. Мягких 404 нет.
- robots.txt: `Allow: /` + `Sitemap: https://regiondorstroy.com/sitemap.xml`. sitemap.xml: 3 URL (главная, аренда, щебень), без 404/noindex-страниц, формат валиден.
- privacy.php / consent.php: и `<meta name="robots" content="noindex">`, и `X-Robots-Tag: noindex`; в sitemap нет. Админка: `noindex, nofollow`, 302 на логин.
- canonical и og:url на каждой индексируемой странице абсолютные и верные; hreflang нет (один язык — это нормально).
- Title 56–65 симв., description 145–165 — уникальны; один H1 на странице; JSON-LD есть (главная: HomeAndConstructionBusiness; внутренние: Service + BreadcrumbList).
- Сжатие gzip на HTML/XML (главная 96 КБ → 16 КБ). Статика `cache-control: max-age=31536000`. Нет внешних CSS/JS: 12 КБ инлайн-CSS + 7,5 КБ инлайн-JS, блокирующих запросов нет. Hero и 2 шрифта предзагружаются (`fetchpriority=high`). Картинки только WebP, lazy на нижних, alt везде.
- Скорость (Lighthouse prod, M0): mobile Performance 96/100/98, SEO 100 везде, LCP 2,5 с главная (1,0 с на внутренних), CLS 0–0,016, TBT ≤140 мс; desktop 100. INP лабораторно не измеряется.
- Яндекс-верификация: файл `/yandex_f44cfbcdfd8eeb6e.html` отдаёт 200, хост Verified. Meta-тегов yandex/google-verification нет (для Яндекса файла достаточно).
