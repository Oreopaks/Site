# Wordstat: гипотезы спроса (ручная проверка)

Wordstat API не используем. Фразы ниже — гипотезы из услуг/техники/материалов, которые реально есть в `db/seed.sql` и `db/seed-pages.sql`. Города/районы области — только гипотеза спроса.

## Как проверять

1. Открыть https://wordstat.yandex.ru (вход под аккаунтом Яндекса).
2. Регион: «Орловская область» (для фраз с Орлом можно и «Орёл», но записывать единообразно — указать в заметке).
3. Вводить фразу в кавычках-режиме без операторов (сначала «как есть»), затем при необходимости `"!фраза"` для точной частоты.
4. Записать «Число запросов» за месяц в столбец «частота». Во вкладке «Динамика» посмотреть сезонность (пики, спад) — коротко в «заметку» (напр. «пик май–сен»).
5. Из правой колонки «Что ещё искали» выписать 2–3 новые формулировки с частотой — в «заметку».
6. Частота < ~10 — спроса практически нет, фразу не брать в расчёт.

Целевые страницы: опубликованы `/arenda-spetstekhniki/`, `/shcheben-pesok-grunt/`. `/asfaltirovanie/` и `/blagoustroystvo/` в коде есть, но скрыты (404) до ответов владельца в анкете «Факты».

## Гипотезы, которые решают

- Строки 21–24, 26–28, 30: если суммарный спрос заметен, срочно получить от владельца ответы по `fact_asphalt_*` и `fact_blago_works` и опубликовать скрытые посадочные.
- Строка 25 (СНТ/щебёночные дороги): если частота выше, чем у «асфальтирования», нужна отдельная посадочная; ответ владельца — `fact_snt`.
- Строка 29: высокая частота — отдельная страница «Планировка участков» (услуга №6 в сиде).
- Строка 8: заметный спрос на автогрейдер — отдельная страница под ДЗ-122Б-7; иначе остаётся блоком на общей странице аренды.
- Строка 20: есть отдельный спрос на ПГС/отсев — вынести в свою страницу; иначе оставить в `/shcheben-pesok-grunt/`.
- Строки 12–16: если фракции/порода ищутся отдельно и в сумме значимо — подзаголовки/блоки с фракциями на странице материалов, при очень высокой частоте — отдельные страницы на «щебень гранитный»/«известняковый».
- Строка 10: если Мценск/Ливны дают спрос — страницы по районам (только если владелец подтвердит выезд, `fact_zone`).
- Сравнение «за час» и «за смену» (3, 5, 6): определяет, что выносить в заголовок и первую цену на странице аренды.
- Строки 1 vs 2/7/9: если общий запрос слабее конкретных техник — отдельные посадочные под экскаватор/каток/самосвал.
